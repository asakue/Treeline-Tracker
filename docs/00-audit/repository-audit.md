# Аудит репозитория Treeline Tracker (Repository Audit)

**Дата проведения:** 21 сентября 2026 г. (Актуализировано: 24 сентября 2026 г.)  
**Версия кодовой базы:** 0.4.0 (с обновлениями безопасности и тестового покрытия)

## 1. Введение и цели аудита

Целью аудита является детальная ревизия кодовой базы `asakue/Treeline-Tracker`, определение текущей архитектуры, выявление работающих, симулированных и завершенных компонентов, анализ технического долга, уязвимостей безопасности, статуса разрешения выявленных дубликатов и оценка покрытия тестами.

---

## 2. Обзор технологического стека

- **Фреймворк:** Next.js 15.3.8 (App Router), React 18.3.1, TypeScript 5.
- **Стилизация:** Tailwind CSS 3.4.1, Tailwind-Merge, Lucide-React, Radix UI primitives (`shadcn/ui`).
- **Картография:** Leaflet 1.9.4, React-Leaflet 4.2.1, `geofire-common` гео-хеширование.
- **ИИ-компонент:** Genkit 1.20.0 (`@genkit-ai/google-genai`), Google Generative AI (`@google/genai`).
- **Криптография и Безопасность:** Web Crypto API (Ed25519, AES-256-GCM AEAD, SHA-256), децентрализованный менеджер идентичности, защита от повторов.
- **Стейт и хранение:** React State, LocalStorage / Repository Pattern (`src/core/repositories`), Firebase SDK v11.9.1 (Auth, Firestore RBAC).
- **Тестирование и верификация:** Vitest 5.0.1, React Testing Library 16.3.3, `@testing-library/jest-dom`, JSDOM.
- **Сборка и линтинг:** Standalone output, ESLint 9 (Flat Config), Next Compiler.

## 5. Анализ безопасности и результаты закрытия рисков

1. **Защита геоданных от перехвата (E2EE):**  
   *Статус:* `MITIGATED & IMPLEMENTED`. Внедрен криптографический сервис на Web Crypto API. Координаты шифруются ключом группы AES-256-GCM перед передачей.
2. **Аутентификация авторства пакетов:**  
   *Статус:* `MITIGATED & IMPLEMENTED`. Каждый пакет подписывается Ed25519 закрытым ключом автора. Подделка координат третьей стороной отвергается получателем.
3. **Защита от атак повторного воспроизведения (Replay Attacks):**  
   *Статус:* `MITIGATED & IMPLEMENTED`. Внедрен модуль `replay-protection.ts` с фильтрацией по 10-минутному окну свежести, кэшем `messageId` и монотонным инкрементом `sequence`.
4. **Хранение секретов и ключей:**  
   *Статус:* `MITIGATED & ENFORCED`. Настроен `.env.example`, `.gitignore` дополнен исключениями приватных ключей, активирован pre-commit скрипт `scripts/secret-scan.mjs` и сканирование TruffleHog. Приватные ключи пользователей хранятся исключительно в изолированном локальном хранилище клиента.
5. **Ролевой контроль доступа (RBAC):**  
   *Статус:* `IMPLEMENTED`. Доменная типизация ролей (`hiker`, `guide`, `rescuer`, `admin`) согласована с декларативными правилами `firestore.rules`.
