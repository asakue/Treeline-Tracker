# ADR-006: Стратегия сквозного шифрования (E2EE) и аутентификации

**Статус:** `ACCEPTED`  
**Дата:** 18 сентября 2026 г.  

## Контекст
Передача точных координат через открытый радиоэфир или сторонние серверы несет прямую угрозу безопасности участников. Данные должны быть защищены от перехвата, модификации и подделки.

## Решение
1. **Идентификация и подписи:** Ключевые пары Ed25519 для подписи каждого исходящего пакета.
2. **Шифрование данных:** Симметричное аутентифицированное шифрование (AEAD) алгоритмами AES-256-GCM или ChaCha20-Poly1305 с уникальным `nonce` для каждого пакета.
3. **Защита от повторов (Anti-Replay):** Использование монотонно возрастающего счетчика `sequence`, `messageId` и временного окна (Freshness Window <= 10 минут).
4. **Запрет на самописную криптографию:** Использование стандартных Web Crypto API и аудированных библиотек (`@noble/ciphers`, `@noble/curves`).

## Последствия
- Полный Zero-Knowledge: ни сервер, ни ретрансляторы не имеют доступа к координатам.
- Необходимость управления сессионными ключами групп.
