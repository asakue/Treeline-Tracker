# ADR-001: Выбор Next.js App Router в качестве платформы

**Статус:** `ACCEPTED`  
**Дата:** 18 сентября 2026 г.  

## Контекст
Проект требует создания интерактивного веб-клиента с поддержкой оффлайн-режима, интеграции серверных ИИ-инструментов (Genkit/Gemini) и возможностью развертывания в контейнерном окружении (Cloud Run).

## Рассмотренные альтернативы
1. **React SPA (Vite):** Быстрый клиент, но требует отдельного Node.js бэкенда для безопасного проксирования ключей ИИ.
2. **Next.js App Router (15+):** Единый full-stack фреймворк, строгая типизация, изоляция секретов на сервере (`app/api/*`), встроенная оптимизация.

## Решение
Выбрать **Next.js 15 с App Router** и standalone-сборкой.

## Последствия
- Серверные секреты (Gemini API Key) надежно изолированы на бэкенде.
- Клиентские компоненты картографии требуют динамического импорта (`dynamic(..., { ssr: false })`).
