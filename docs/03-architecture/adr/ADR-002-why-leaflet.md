# ADR-002: Выбор Leaflet для картографического ядра

**Статус:** `ACCEPTED`  
**Дата:** 18 сентября 2026 г.  

## Контекст
Приложению требуется легковесный, надежный картографический движок для отображения топографических карт, отрисовки полилиний маршрутов, маркеров туристов и зон поиска с поддержкой кэширования тайлов для оффлайн-работы.

## Рассмотренные альтернативы
1. **Google Maps JS API:** Требует постоянного интернет-соединения для загрузки тайлов и закрытых API-ключей с биллингом. Не подходит для автономного оффлайн-режима.
2. **Mapbox GL / MapLibre GL:** Высокая производительность векторных тайлов (WebGL), но тяжеловесный бандл и избыточная сложность для базового 2D-отображения.
3. **Leaflet (с OpenStreetMap / OpenTopoMap):** Легковесный (открытый стандарт), гибкая поддержка растровых топографических тайлов, легко кэшируется в Service Worker.

## Решение
Использовать **Leaflet 1.9** и библиотеку обертки **React-Leaflet 4.2**.

## Последствия
- Полная автономность и независимость от платных картографических сервисов.
- Требуется отключение SSR для компонентов карты.
