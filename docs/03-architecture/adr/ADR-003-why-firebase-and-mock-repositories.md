# ADR-003: Паттерн репозиториев для абстракции Firebase и LocalStorage

**Статус:** `ACCEPTED`  
**Дата:** 18 сентября 2026 г.  

## Контекст
Приложение должно одинаково надежно работать как в полностью оффлайновом режиме без аккаунтов (автономный поход), так и в режиме синхронизации через облако при наличии связи.

## Решение
Внедрить паттерн **Repository** (`IGroupRepository`, `IRouteRepository`, `ILocationRepository`).  
- Реализация `LocalStorageRepository` используется по умолчанию для мгновенного старта и оффлайн-работы.
- Реализация `FirebaseRepository` используется как адаптер синхронизации.
- Реализация `MockRepository` используется для автотестов.

## Последствия
- UI-компоненты полностью развязаны от деталей реализации БД.
- Легкая замена облачного провайдера в будущем без модификации бизнес-логики.
