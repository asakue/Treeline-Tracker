# ADR-005: Гибридная модель подключения (Internet + Mesh) и отказоустойчивость

**Статус:** `ACCEPTED`  
**Дата:** 18 сентября 2026 г.  

## Контекст
Туристическая группа переходит из зоны покрытия базовых станций 4G/LTE в горные ущелья без связи и обратно. Переключение каналов передачи должно происходить прозрачно для пользователя без потери пакетов.

## Решение
Реализовать компонент **Transport Manager** с контроллером отказоустойчивости (Failover Controller):
- Приоритет 1: `InternetTransport` (если `navigator.onLine` и успешный пинг).
- Приоритет 2: `MeshCoreTransport` (при недоступности интернета).
- Приоритет 3: `OfflineStoreAndForward` (при отсутствии радиососедей).
- При восстановлении интернета — автоматический сброс буфера оффлайн-пакетов.

## Последствия
- Высокая надежность доставки и нулевая потеря критических пакетов (SOS).
- Дополнительная нагрузка на клиент для дедупликации пришедших пакетов.
