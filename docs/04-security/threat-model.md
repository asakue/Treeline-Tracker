# Модель угроз (Threat Model & Security Matrix)

**Статус документа:** `COMPLETED`  
**Категория:** Безопасность и Приватность (`04-security`)

---

## 1. Защищаемые активы (Protected Assets)

| ID | Наименование актива | Описание | Критичность |
|---|---|---|---|
| **A1** | **Current Location** | Текущие точные географические координаты участника | Critical |
| **A2** | **Location History** | История перемещений, контрольные точки и треки | High |
| **A3** | **User Identity** | Имя, идентификатор пользователя и цифровой профиль | Medium |
| **A4** | **Group Membership** | Состав группы, список участников и права доступа | High |
| **A5** | **Emergency Status** | Сигнал бедствия SOS, статус здоровья и заряд батареи | Critical |
| **A6** | **Messages** | Текстовые сообщения внутри группового чата | High |
| **A7** | **Cryptographic Keys** | Закрытые ключи подписи и групповые симметричные ключи | Critical |

---

## 2. Модель нарушителя (Threat Actors)

| ID | Тип нарушителя | Мотивация и возможности |
|---|---|---|
| **T1** | **Passive Radio Listener** | Пассивный перехват незашифрованного радиоэфира LoRa или Wi-Fi в радиусе связи. |
| **T2** | **Malicious Group Member** | Недобросовестный участник группы с валидным групповым ключом, пытающийся подделать координаты других. |
| **T3** | **Compromised Backend** | Взлом или компрометация облачной базы данных / сервера синхронизации. |
| **T4** | **Stolen Device** | Физическая кража разблокированного смартфона одного из участников. |
| **T5** | **Fake Mesh Node / MitM** | Развертывание поддельного узла ячеистой сети для перехвата, модификации или сброса пакетов. |
| **T6** | **Replay Attacker** | Запись старых пакетов координат или отмененных сигналов SOS и их повторная отправка в эфир. |
| **T7** | **Traffic Observer / ISP** | Анализ метаданных сетевого трафика (объем, частота пакетов, тайминги). |

## 3. Матрица угроз и мер защиты (Threat Matrix)

| Угроза | Ассет | Актор | Вектор атаки | Мера противодействия (Mitigation) | Статус |
|---|---|---|---|---|---|
| **Перехват координат** | A1, A2 | T1, T3, T5 | Сниффинг радиоэфира или доступ к БД | Сквозное шифрование (E2EE) AES-256-GCM / ChaCha20 | `PROTOTYPE` |
| **Фальсификация координат** | A1 | T2, T5 | Отправка фейковых координат от чужого имени | Цифровая подпись каждого пакета закрытым ключом Ed25519 | `PROTOTYPE` |
| **Атака повтором (Replay)** | A1, A5 | T5, T6 | Повтор ранее записанного пакета локации или SOS | Использование `messageId`, `sequence` и окна времени (Freshness) | `PROTOTYPE` |
| **Модификация пакета** | A1, A5, A6 | T5 | Изменение координат или текста в пути | Контроль целостности через AEAD Authentication Tag | `PROTOTYPE` |
| **Утечка из облака** | A1, A6 | T3 | Дамп базы данных на сервере | Zero-Knowledge архитектура: сервер хранит только `ciphertext` | `PROTOTYPE` |
| **Ложный сигнал SOS** | A5 | T5, T6 | Вброс паники в группу | Цифровая подпись автора + валидация членства в группе | `PROTOTYPE` |
| **Извлечение ключей** | A7 | T4 | Извлечение секретов из хранилища устройства | Изоляция в Secure Storage / Web Crypto API | `PLANNED` |
| **Анализ трафика** | A3, A7 | T7 | Корреляция активности и размера пакетов | Фиксированный размер полезной нагрузки (Padding) | `RESEARCH` |
