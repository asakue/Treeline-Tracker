# Управление ключами шифрования (Key Management)

**Статус документа:** `COMPLETED`  
**Категория:** Безопасность и Приватность (`04-security`)

---

## 1. Иерархия ключей

1. **Master Identity Key (Ключ пользователя):** Пара Ed25519, генерируемая один раз. Приватный ключ никогда не экспортируется.
2. **Group Shared Secret (Симметричный групповой ключ):** 256-битный ключ (AES-256), генерируемый создателем группы при инициализации.
3. **Session Nonce:** 96-битный одноразовый вектор инициализации, генерируемый криптографическим генератором псевдослучайных чисел для каждого отдельного пакета.

---

## 2. Распространение групповых ключей

- **Оффлайн-режим (QR-код):** Руководитель группы генерирует анимированный или статический QR-код, содержащий `groupId` и симметричный ключ, зашифрованный открытым ключом подключающегося участника.
- **Онлайн-режим:** Безопасный обмен через диффи-хеллмановский протокол (X25519) при наличии интернет-соединения.

---

## 3. Ротация ключей при исключении участника

При удалении или выходе участника из состава группы:
1. Лидер инициирует смену группового ключа (`RotateGroupKey`).
2. Новый ключ рассылается только оставшимся доверенным участникам.
3. Пакеты, зашифрованные старым ключом, продолжают приниматься как архивные, но новые трансляции со старым ключом отклоняются.
